# SE4All 2027 website

Single page site for the International Workshop on Software Engineering and AI for All, co-located with ICSE 2027 in Dublin.

## Publish on GitHub Pages
1. Copy `index.html` and the `assets` folder into the root of the `se4all.github.io` repository.
2. Commit and push. GitHub Pages serves the site at https://se4all.github.io/ within a minute or two.

## Editing
Everything lives in `index.html`. Dates, committee members, and topics are plain HTML, so edit the text in place.
The countdown and timeline read the dates from the `data-date` attributes in the Important dates list. Deadlines are anywhere on Earth, so each `data-date` is set to noon UTC on the day after the printed date.

## Logo files
`assets/` contains the SE4All logo in SVG (year specific and year free, light and dark) plus favicon and social preview images.
